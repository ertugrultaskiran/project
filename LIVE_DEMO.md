# 🌐 LIVE DEMO - IT Ticket Classifier

## 🚀 Production URL

**Live Application:** https://it-ticket-classifier.onrender.com

## ✨ Features Available

### 📊 Analytics Dashboard
- **Real-time Charts** powered by Chart.js
- Ticket trends over time (line chart)
- Category distribution (doughnut chart)
- Model performance comparison (bar chart)
- Confidence distribution (histogram)
- Interactive date range filtering

### 🤖 AI-Powered Features
- **Sentiment Analysis** - Detects positive, negative, neutral, urgent tones
- **Priority Detection** - Automatically assigns HIGH/MEDIUM/LOW priority
- **Smart Routing** - Routes tickets to appropriate departments
- **SLA Prediction** - Estimates resolution time based on priority & category
- **Similar Tickets Finder** - TF-IDF cosine similarity for finding related past tickets

### 💬 Interactive Chatbot
- **Classic Mode** - Simple ticket classification
- **AI Enhanced Mode** - Full AI analysis with sentiment, priority, routing, and SLA
- Real-time classification with confidence scores
- Beautiful UI with badges and color-coded responses

### 📈 Live Statistics
- 50 mock tickets pre-generated
- Multiple ML models (LSTM, BERT, Baseline, Ensemble)
- 87.4% average confidence
- 8 ticket categories (Access, Hardware, Network, Software, Storage, HR Support, Purchase, Admin Rights)

## 🔧 Technology Stack

- **Backend:** Flask (Python)
- **Frontend:** HTML5, CSS3, JavaScript, Chart.js
- **AI/ML:** scikit-learn, TextBlob (sentiment analysis), TF-IDF (similarity)
- **Deployment:** Docker + Render.com
- **Data:** Mock data generation for demo purposes

3. **Try the Chatbot:**
   - Click the chatbot widget (bottom-right)
   - Switch between Classic and AI Enhanced modes
   - Type an IT support request (e.g., "I need access to SAP system")
   - See instant classification with AI analysis
4. **View Classification History:** Check past tickets in the table
