🧠 Adım 3: Word2Vec + BiLSTM (Deep Learning)

Neden LSTM? Cümle sırasını ve bağlamı anlar, TF-IDF'ten daha güçlü

Konfigürasyon:

  • Word2Vec: 200-dim embeddings, skip-gram
  • BiLSTM: 128 units, bidirectional
  • Dropout: 0.3 (overfitting önleme)
  • Epochs: 15, early stopping

Sonuç:

Metrik Baseline LSTM İyileştirme
Test Accuracy %86.04 %87.00 +0.96%
Training Süresi 5 dk ~45 dk (GPU) -
Model Boyutu 10 MB ~100 MB -
✅ Başarı: Deep learning %1 iyileştirme sağladı!
🤔 Düşüncem: "Sadece %1 artış... İki modeli birleştirsem ne olur? Ensemble denemeliyim - belki birbirinin hatalarını kapatır."

🔀 Adım 4: Ensemble Model (Baseline + LSTM)

Neden ensemble? İki modelin güçlü yönlerini birleştirmek

Strateji: Weighted average of probabilities

# Ensemble: İki modelin tahminlerini birleştir baseline_probs = baseline_model.predict_proba(text) lstm_probs = lstm_model.predict(text) # Farklı ağırlıklar denedim: ensemble = 0.5 * baseline_probs + 0.5 * lstm_probs # Equal ensemble = 0.4 * baseline_probs + 0.6 * lstm_probs # LSTM heavy

Sonuç:

Yaklaşım Accuracy İyileştirme
Baseline %86.04 -
LSTM %87.00 +0.96%
Ensemble %88.40 +2.36%
✅ Başarı: Ensemble %2.36 toplam iyileştirme!
🤔 Düşüncem: "Güzel! Ama modern AI'da BERT kullanılıyor. Transfer learning ile belki %90+ çıkabilirim. Hem Türkçe desteği de gerekiyor..."

🌍 Adım 5: BERT Fine-Tuning (Transfer Learning)

Neden BERT?

  • State-of-the-art transformer model
  • Çok dilli destek (104 dil)
  • Context-aware (cümle bağlamını anlıyor)
  • Pre-trained (Wikipedia'dan öğrenmiş)

Model seçimi: bert-base-multilingual-cased

Neden bu model?

  • ✅ Türkçe + İngilizce destekliyor
  • ✅ Case-sensitive (büyük/küçük harf önemli)
  • ✅ 110M parametre (orta boyut, hızlı)

     ↓
[2] Sentiment Analysis  
     → Keywords: "sinirliyim" → Sentiment: NEGATIVE 😔
     ↓
[3] Classification
     → BERT Model → Category: Hardware (%93)
     ↓
[4] Template Selection
     → Template: Hardware + Urgent + Negative
     ↓
[5] Response Generation
     → Empathy: "😔 Yaşadığınız sorunu anlıyorum..."
     → Steps: [4 acil adım]
     → ETA: "15-30 dakika"
     ↓
[6] Escalation Check
     → Confidence: 93% → OK
     → Intent: Urgent → Escalation ready if not solved
     ↓
[7] Context Tracking
     → Save to conversation history
     → Multi-turn support ready
     ↓
Output: Full conversational response!
