Figure 15: Use Case Model - UML Use Case Diagram

Use Case Descriptions:

  • Classify IT Ticket: End user submits ticket text (Turkish/English), system classifies into 8 categories with confidence score
  • Chat with Conversational AI: End user interacts with AI assistant, receives contextual responses with sentiment analysis
  • Select Classification Model: User chooses between Baseline, LSTM, Ensemble, or BERT models based on speed/accuracy needs
  • View Classification History: IT Support Agent reviews all classified tickets with filters by category/confidence
  • Review Statistics: Agent views dashboard metrics (total tickets, average confidence, category distribution)
  • Escalate Uncertain Ticket: System automatically escalates tickets with confidence <65% or urgent intent to human agent
  • Monitor System Health: System Administrator checks API health, model status, and system performance metrics
  • Reset Conversation: End user clears conversation history to start fresh interaction with chatbot

Figure 16: Object Model - UML Class Diagram

Class Relationships:

  • WebApp orchestrates the entire system, uses ConversationalAssistantV2 and ModelManager
  • ModelManager manages all classification models (Baseline, LSTM, BERT, Ensemble)
  • EnsembleModel combines predictions from BaselineModel and LSTMModel (composition)
  • ConversationalAssistantV2 uses IntentDetector, SentimentAnalyzer, and ResponseGenerator
  • TicketHistory stores and manages all classified tickets for review and analysis
  • All model classes implement a common interface: predict(text) → (category, confidence)
